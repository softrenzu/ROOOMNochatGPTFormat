# ROOOMNochatGPTFormat

日本語の見積書、依頼書、申請資料、報告書などを、AI生成物にありがちな不自然な構成や装飾を避け、日本企業で実際に使われる業務書類に近い形で作成するためのAgent Skillです。

## 目的

このSkillは文章を人間らしく「ごまかす」ことを目的とするものではありません。目的は、業務書類として不要なAI特有の装飾・冗長表現・画一的な章立てを排除し、既存帳票、公式様式、社内様式、一般的な日本企業の文書慣行を優先して、実務でそのまま使いやすい成果物を作ることです。

## 主な対象

- 見積書
- 見積依頼書
- 依頼書
- 提案書
- 報告書
- 稟議資料
- 申請資料
- 請求書の下書き
- 業務連絡文書
- 補助金・行政申請の添付資料

## 基本原則

1. 既存テンプレートがある場合は新規デザインせず、その様式を最優先します。
2. 行政・補助金等で公式様式がある場合は、必ず公式様式へ直接記入します。
3. 見積書は日本企業で一般的な帳票構成を使い、カードUI、過剰な色、巨大見出し、アイコンを避けます。
4. 「目的・背景・課題・解決策・期待効果」を機械的に並べるようなAI定型構成は、必要な場合を除き使いません。
5. 数字、税、単価、数量、合計、日付、宛名、発行者など業務上の必須情報を優先します。
6. 第三者発行書類を第三者が発行したように偽装しません。下書きは下書きと明記します。
7. Windows 11上で扱う日本語ファイル名は、通常の日本語、半角英数字、アンダースコアを基本とします。

## 構成

- `SKILL.md` : Skill本体
- `references/quotation.md` : 見積書ルール
- `references/business-documents.md` : 一般業務書類ルール
- `references/quality-check.md` : 納品前チェック

## 利用例

ChatGPT / Codex / Agent環境でこのリポジトリの `SKILL.md` を読み込ませた上で、次のように依頼します。

- 「この見積書を日本企業の通常の見積書らしく作成」
- 「この補助金の公式様式に直接記入」
- 「この依頼書をAIっぽいデザインにせず、普通の社内文書にして」
- 「このExcel見積を既存様式を崩さず更新」

## 方針

見栄えより提出可能性、業務慣行、既存様式との一致を優先します。
