# 納品前品質チェック

完成ファイルを納品・共有・提出する前に、以下を確認する。

## 1. ファイル

- ファイル名が正しい
- 拡張子が正しい
- 指定されたファイル数と一致する
- ファイルが破損していない
- Windows 11で日本語ファイル名が正常に表示される
- 不要な一時ファイル、バックアップ、下書きが混在していない
- 提出不可書類は提出用フォルダと分離されている

## 2. 内容

- 宛名が正しい
- 会社名・氏名・部署名が正しい
- 日付が正しい
- 住所・連絡先が正しい
- 必須項目がすべて埋まっている
- 仮値、ダミー文字列、TODO、XXX、未確認の記載が残っていない
- 同じ内容の重複記載がない
- AI定型句や不要な営業文句が残っていない

## 3. 数値

- 数量と単価を再計算した
- 小計を再計算した
- 消費税を再計算した
- 合計金額を再計算した
- 税込・税抜の表記が一致している
- 桁区切りと通貨単位が統一されている
- 日付・期間・回数に矛盾がない

## 4. 書式

- 既存テンプレートがある場合、その様式を維持している
- 公式様式がある場合、独自様式へ置き換えていない
- フォントが日本語Windows環境で利用可能
- 文字切れ、セル切れ、表のはみ出しがない
- 改ページ位置が不自然でない
- PDFの場合、全ページを目視確認した
- Excelの場合、数式エラーがない

## 5. 行政・補助金

- 募集要項の必要書類一覧と一件ずつ照合した
- 指定様式の版・年度が正しい
- ページ数・文字数制限を満たしている
- 指定ファイル形式を満たしている
- 指定ファイル名がある場合、それに従っている
- 必須添付がそろっている
- 第三者発行書類を自作・偽装していない

## 6. ZIP

ZIPを作成する場合のみ実施する。

- Unicode対応方式で圧縮した
- 作成後に実際に別フォルダへ解凍した
- 圧縮前後のファイル数が一致した
- 圧縮前後のファイル名が完全一致した
- 日本語ファイル名に文字化け、代替文字、崩れがない
- 解凍後の全ファイルが開ける

1件でも不一致がある場合は、そのZIPを納品しない。

## 7. 最終判定

次の3区分で判定する。

- 提出可能: 必須確認をすべて通過
- 要確認: 正しい情報が不足しており、提出前に確認が必要
- 提出不可: 下書き、第三者発行待ち、公式様式未反映、破損、計算不一致などがある

「要確認」「提出不可」のファイルを、提出可能な完成書類と同じ提出用フォルダに混在させない。
